# 04. 8주 학습 로드맵 (목표 Lv.3 ~ Lv.4)

> 하루 1.5~2시간, 주 5~6일 기준입니다. 이미 아는 주차는 건너뛰세요.
> 각 주차 추천 문제는 [06-problem-bank.md](06-problem-bank.md)에 있습니다.

| 주차 | 주제 | 목표 | 완료 기준 |
| --- | --- | --- | --- |
| 1 | 구현, 문자열, 배열 | 시험 1번 유형 만점 | 시뮬레이션 문제 8개, 실수 체크리스트 작성 |
| 2 | 정렬, 그리디, 완전 탐색 | 정렬 키와 그리디 증명 감각 | 고득점 Kit 정렬·그리디·완전탐색 완료 |
| 3 | 해시, 스택, 큐, 덱 | 자료구조 선택 속도 | 고득점 Kit 해시·스택/큐 완료 |
| 4 | DFS, BFS, 백트래킹 | 격자 BFS를 10분 안에 작성 | 템플릿 `bfs_grid`를 보지 않고 작성 |
| 5 | 이분 탐색, 파라메트릭 서치 | 경계 실수 0 | `lower_bound`, `parametric` 템플릿을 외워서 작성 |
| 6 | 힙, 그래프(다익스트라, 유니온 파인드, 위상 정렬) | 그래프 모델링 | 그래프 4문제, 다익스트라를 외워서 작성 |
| 7 | 동적 계획법 | 점화식 세우기 | DP 6문제, 1차원·2차원 각각 |
| 8 | **실전 모의고사** | 120분 4문항 시간 관리 | 기출 2세트 + 자체 모의고사 2회, 평균 750점 이상 |

## 주간 루틴

| 요일 | 활동 |
| --- | --- |
| 월~목 | 주제별 문제 2~3개 (새 문제 70%, 복습 30%) |
| 금 | 템플릿 손으로 쓰기: A4에 써 본 뒤 웹 에디터에서 확인 |
| 토 | **90~120분 타이머 모의 세션** (4문제, IDE 없이 프로그래머스 웹 에디터만) |
| 일 | `progress_report.py`로 약점 확인, 오답 다시 풀기 |

## 시험 D-day 역산 체크포인트

- **D-14**: 공식 사이트에서 접수(정기시험 일정 확인). 응시 언어는 접수할 때 정하며 바꿀 수 없습니다.
- **D-7 ~ D-1**: 사전 테스트로 PC, 웹캠, 스마트폰 카메라, 신분증 업로드를 점검합니다.
- **D-3**: 새 유형 학습은 멈추고 기출 다시 풀기와 템플릿 복습만 합니다.
- **D-1**: 장비 거치(스마트폰 거치대, 충전기), A4 1장, 신분증을 준비합니다.
