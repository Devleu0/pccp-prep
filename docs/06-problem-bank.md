## 3. 모의고사 구성법 (8주 차)

프로그래머스 난이도로 **Lv.1 1개 + Lv.2 2개 + Lv.3 1개**를 아직 안 푼 문제에서 무작위로 골라 120분 타이머로 풉니다.
채점은 프로그래머스 제출 결과를 쓰되, 정확성과 효율성을 따로 기록해 실제 시험처럼 부분 점수를 계산합니다.
