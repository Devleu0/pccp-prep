# 03. 목표 등급별 대비 전략

## 1. 점수 모델 (추정)

문항당 약 250점으로 잡으면 목표별 필요 점수는 다음과 같습니다.

| 목표 | 필요 점수 | 현실적인 점수 구성 예 |
| --- | --- | --- |
| 합격(Lv.1) | 400+ | 1번 만점 + 2번 60% |
| **Lv.3 (채용 우대 기준)** | 600+ | 1, 2번 만점 + 3번 40% |
| Lv.4 | 750+ | 1, 2, 3번 만점 |
| Lv.5 | 900+ | 1~3번 만점 + 4번 60% |

**핵심**: Lv.4까지는 4번을 못 풀어도 됩니다. 1~3번을 **효율성까지 만점**으로 받는 것이 가장 확실한 길입니다.

## 2. 4대 원칙

1. **정확성 > 속도**: 부분 점수가 있으니 손으로 반례를 만드는 습관이 등급을 결정합니다.
2. **복잡도를 먼저 계산**: 입력 크기를 보고 허용 복잡도를 정한 뒤에 코딩합니다.

   | 입력 크기 N | 허용 복잡도 | 떠올릴 기법 |
   | --- | --- | --- |
   | ≤ 10 | O(N!) | 순열, 백트래킹 |
   | ≤ 20 | O(2^N) | 부분집합, 비트마스크 |
   | ≤ 500 | O(N^3) | 플로이드, 3중 반복 |
   | ≤ 5,000 | O(N^2) | 2차원 DP, 이중 반복 |
   | ≤ 10^6 | O(N log N) | 정렬, 힙, 이분 탐색 |
   | ≤ 10^9 | O(log N) | 파라메트릭 서치, 수학 |

3. **IDE 없는 환경에 적응**: 자동 완성과 디버거 없이 웹 에디터에서 푸는 연습을 합니다. 표준 라이브러리 API는 외워 둡니다(`templates/python`).
4. **언어는 가장 익숙한 것으로**: 구현량이 많은 시험이라 Python이 유리한 편입니다. C++/Java를 쓴다면 입출력이 아니라 `solution()` 함수 시그니처 방식이라는 점에 익숙해지세요.

## 3. 현재 실력별 진입 경로

| 현재 실력 (프로그래머스 기준) | 목표 | 집중 영역 | 기간 |
| --- | --- | --- | --- |
| Lv.1 문제도 막힘 | 합격 | 문법, 구현, 문자열, 정렬 | 8주 이상 (PCCE 먼저 권장) |
| Lv.1은 풀고 Lv.2가 어려움 | Lv.3 | 해시, 스택/큐, BFS/DFS, 이분 탐색 | 8주 |
| Lv.2 대부분 해결 | Lv.4 | 효율성, 힙, DP, 그래프, 시간 단축 | 4~6주 |
| Lv.3 해결 가능 | Lv.5 | 백트래킹 가지치기, 4번 대비 모의고사 | 2~4주 |

## 4. 약점 관리 루프 (매주 반복)

```text
풀이 → tracker/problems.csv 기록 → progress_report.py 로 유형별 성공률 확인
    → 성공률 60% 미만 유형을 다음 주 1순위로 → 오답 문제는 3일 후, 7일 후 다시 풀기
```

- **기록 규칙**: 30분 안에 못 풀면 해설을 보고, 원인을 `note` 열에 한 줄로 남깁니다(예: "경계 조건", "복잡도 착각", "API 기억 안 남").
- **오답 원인 분류**: 원인이 '구현 실수'면 체크리스트를 보강하고, '아이디어 부족'이면 같은 유형 문제를 2개 더 풉니다.
