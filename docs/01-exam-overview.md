# 01. PCCP 시험 개요

> 검증일 2026-11-04. 공식 페이지에서 확인한 항목은 ✅, 후기나 학교 공지 같은 2차 출처로 확인한 항목은 ⚠️ 로 표시합니다.

## 1. 기본 정보

| 항목 | 내용 | 근거 |
| --- | --- | --- |
| 정식 명칭 | 코딩전문역량인증 (Programmers Certified Coding Professional) | ✅ 공식 |
| 주관 | (주)그렙 / 프로그래머스, 한국직업능력연구원 등록 민간자격 | ⚠️ 후기 |
| 대상 | SW 전문가 및 상급 학습자 | ✅ 공식 |
| 시험 시간 | 120분 | ✅ 공식 |
| 문항 | 4문항, 모두 **코드 작성** | ✅ 공식 |
| 언어(택1) | Python, Java, JavaScript, C, C++, C# | ✅ 공식 (주 1) |
| 응시료 | 50,000원 | ✅ 공식 (주 2) |
| 유효기간 | 2년 | ✅ 공식 |
| 시행 | 정기시험 (연간 일정은 공식 사이트에 공지), 학교·기업 단체 응시도 있음 | ✅ 공식 메인 / ⚠️ 학교 공지 |

- 주 1: 공식 페이지 본문에는 "4종 개발 언어 중 선택"이라는 옛 문구가 남아 있지만, 과목 목록에는 6개 언어가 나옵니다. 접수 화면에서 실제로 고를 수 있는 언어를 확인하세요. 단체 응시는 언어가 제한되기도 합니다(예: 2026-1학기 국민대 단체 응시는 C++, Python, Java만 가능).
- 주 2: 2022~2024년 후기에는 40,000원으로 나옵니다. 지금은 50,000원으로 올랐습니다.

## 2. 응시 규정 (비대면 IBT)

| 구분 | 규정 |
| --- | --- |
| 감독 | 모니토(Monito) IBT. **웹캠과 스마트폰 카메라 2대**가 모두 연결돼야 응시 가능 ✅ |
| 입실 | 시작 **1시간 전부터 20분 전까지**. 마감 뒤에는 응시 불가 ✅ |
| 자리 비움 | 입실 마감 뒤에는 자리를 비울 수 없음(화장실 포함) ✅ |
| 필기 | **A4 1장 + 필기구**만 허용. 시험 전에 양면이 비었는지 카메라로 확인 ✅ |
| IDE | **외부 IDE 사용 금지** ✅. 시험 페이지에 링크된 언어 레퍼런스는 사용 가능 ⚠️ |
| 환경 | 크롬 최신 버전. 리눅스, 클램쉘 모드, 블루투스 키보드 사용 불가 ⚠️ |
| 신분증 | 주민등록증, 운전면허증, 유효한 여권 등 규정 신분증 ✅ |
| 사전 테스트 | 응시일 **7일 전부터 하루 전까지** PC, 모바일 카메라, 신분증 업로드를 점검 ✅ |
| 제출 | 문항마다 **'코드 제출하기'를 눌러야** 점수에 반영. 마지막 제출이 최종 ⚠️ |
| 결과 | 시험이 끝나고 보통 30분 안에 확인 가능 ⚠️ |

## 3. PCCE와 비교

| | PCCP (전문) | PCCE (필수) |
| --- | --- | --- |
| 문항/시간 | 4문항 / 120분 | 10문항 / 50분 |
| 유형 | 코드 작성 | 빈칸 채우기, 디버깅, 코드 작성 |
| 등급 | Lv.1 ~ Lv.5 | Lv.1 ~ Lv.4 |
| 유효기간 | 2년 | 7년 |

## 4. 활용

- 채용 우대: 많은 기업이 **Lv.3 이상**을 우대 조건으로 내걸고, 일부 기업은 Lv.5를 요구한 사례도 있습니다 ⚠️. 최신 활용 기업은 공식 사이트 '활용 현황' 메뉴에서 확인하세요.
- 프로그래머스 Dev-Matching 같은 채용 이벤트의 코딩테스트를 PCCP로 대신한 사례도 있습니다 ⚠️.
