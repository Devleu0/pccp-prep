# 02. 출제 범위와 채점

## 1. 공식 출제 범위 (5개 영역)

| # | 영역 | 세부 키워드 |
| --- | --- | --- |
| 1 | 기본 프로그램 구현 | 제시된 조건과 요구 사항을 그대로 구현 (시뮬레이션) |
| 2 | 초급 자료구조/알고리즘 | 문자열, 배열, 그리디, 정렬 |
| 3 | 중급 자료구조/알고리즘 | 스택, 큐, 덱, 해시, 이진 탐색, DFS, BFS |
| 4 | 고급 자료구조/알고리즘 | 그래프, 트리, 힙, 동적 계획법(DP) |
| 5 | 정확하고 효율적인 프로그램 | 알맞은 자료구조와 알고리즘을 골라 오류 없이 작성 (시간 복잡도) |

## 2. 등급 기준 (1000점 만점)

| 등급 | 점수 | 공식 역량 설명 (요약) |
| --- | --- | --- |
| 불합격 | 0 ~ 399 | |
| Lv.1 | 400 ~ 499 | 초급 문제 해결, 명시된 절차대로 제한적 과제 해결 |
| Lv.2 | 500 ~ 599 | 중급 문제 해결, 스스로 알고리즘 설계 |
| Lv.3 | 600 ~ 749 | 중상 수준 문제를 **정확히** 해결 |
| Lv.4 | 750 ~ 899 | 상급 문제를 **효율적**으로 해결 |
| Lv.5 | 900 ~ 1000 | 상급 문제를 **최적**으로, 고난도 과제를 주도적으로 해결 |

## 3. 채점 특성 (공식 안내와 후기 종합)

1. **부분 점수 있음**: 문항마다 숨은 테스트 케이스가 여러 개 있고, 통과한 비율만큼 점수를 받습니다. 그래서 완벽하지 않은 풀이라도 내는 편이 항상 낫습니다.
2. **효율성도 채점**: 정답이어도 느리면 감점됩니다. 후기에는 "4문제를 다 풀었다고 생각했는데 Lv.3이 나왔다"는 이야기가 많습니다.
3. **채점 결과를 볼 수 없음**: 공개 예제 2개 안팎만 실행해 볼 수 있고, 제출해도 숨은 케이스 결과는 나오지 않습니다. **반례는 스스로 만들어야** 합니다.
4. **마지막 제출만 반영**: 고친 코드가 더 나쁘면 오히려 손해입니다. 바꾸기 전 코드를 A4나 주석에 남겨 두세요.
5. **문항별 배점은 공개되지 않음**: 1000점 / 4문항이므로 문항당 대략 200~300점으로 잡고 전략을 세웁니다(추정).

## 4. 실제 출제 경향 (공개 기출 기준)

| 회차 | 1번 | 2번 | 3번 | 4번 |
| --- | --- | --- | --- | --- |
| 기출 A | 붕대 감기: 시뮬레이션 | 석유 시추: BFS + 열 단위 집계 | 아날로그 시계: 수학/시뮬레이션 | 수레 움직이기: 백트래킹 |
| 기출 B | 동영상 재생기: 문자열/시간 구현 | 퍼즐 게임 챌린지: 이분 탐색(파라메트릭) | 충돌위험 찾기: 시뮬레이션 + 해시 | 수식 복원하기: 진법 + 완전 탐색 |

정리하면 이렇습니다.

- **1번은 꼼꼼한 구현**(Lv.1 수준). 실수만 안 하면 만점입니다.
- **2~3번은 BFS, 이분 탐색, 해시 + 시뮬레이션**(Lv.2 수준). 효율성이 승부를 가릅니다.
- **4번은 완전 탐색이나 백트래킹 + 까다로운 조건**(Lv.3 수준). 정답률이 20%대입니다.
- 인터넷 검색과 IDE가 금지라서 아주 어려운 알고리즘(세그먼트 트리, 플로우 등)보다는 **기본 유형 + 애드혹** 문제가 주로 나옵니다.
