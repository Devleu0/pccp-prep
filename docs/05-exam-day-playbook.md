# 05. 시험 당일 플레이북

## 1. 시간 배분 (120분)

| 시간 | 할 일 |
| --- | --- |
| 0 ~ 5분 | **4문제 모두 훑어보기**. 제한 조건(N 크기)을 A4에 적고 난이도 순서를 정합니다 |
| 5 ~ 25분 | 1번(구현): 만점이 목표. 끝나면 바로 제출 |
| 25 ~ 60분 | 2번: 복잡도를 먼저 정하고 구현, 엣지 케이스 테스트 후 제출 |
| 60 ~ 95분 | 3번: 막히면 **완전 탐색으로라도 먼저 제출**해 부분 점수를 확보 |
| 95 ~ 115분 | 4번에 도전하거나, 앞 문제의 효율성을 개선 |
| 115 ~ 120분 | 모든 문항이 **'코드 제출하기'** 됐는지 확인 |

**25분 규칙**: 한 문제에서 25분 넘게 진전이 없으면 일단 작동하는 코드를 제출하고 다음 문제로 넘어갑니다.

## 2. 문항별 풀이 절차

```text
1. 문제 다시 읽기: 입출력 형식, 인덱스 0/1 시작, 정렬 기준, 동점 처리
2. 제한 조건으로 허용 복잡도 결정 (03-strategy.md 표)
3. A4에 핵심 아이디어와 반례 후보 3개 적기
4. 구현: 함수를 작게 나누고(파싱 / 핵심 로직 / 답 조립), 변수 이름은 명확하게
5. 공개 예제 실행 → 직접 만든 케이스 추가 실행
6. 제출 → 고칠 때는 이전 정답 코드를 주석으로 보관
```

## 3. 자기 테스트용 엣지 케이스 체크리스트

- [ ] 최솟값 입력 (N=1, 빈 문자열, 원소 1개)
- [ ] 최댓값 입력 (시간 초과 여부를 머릿속으로 계산)
- [ ] 모두 같은 값, 이미 정렬된 입력, 역순 입력
- [ ] 경계: 0, 음수, 자정(00:00/23:59) 같은 시간 경계
- [ ] 격자: 1×1, 한 줄짜리, 가장자리 시작
- [ ] 그래프: 연결되지 않은 노드, 자기 자신으로 가는 간선, 중복 간선
- [ ] 답이 없는 경우의 반환값 (-1, 빈 배열 등)

## 4. 시험 직전 체크리스트

- [ ] 사전 테스트 완료 (응시일 7일 전부터 하루 전까지)
- [ ] 크롬 최신 버전, 불필요한 프로그램과 탭 종료, 알림 끄기
- [ ] 웹캠과 마이크, 스마트폰 카메라 거치 + **충전기 연결**
- [ ] 규정 신분증, 빈 A4 1장, 필기구
- [ ] 화장실은 **시작 20분 전 입실 마감 전**에 다녀오기
- [ ] 시작 1시간 전 입실 (늦어도 20분 전)

## 5. 자주 하는 실수 (후기 종합)

1. 다 풀었다고 생각했는데 **효율성에서 감점**됨 → 제출 전에 최악의 경우 연산 횟수를 계산합니다.
2. 제출 버튼을 누르지 않고 다음 문제로 넘어감 → 풀 때마다 바로 제출합니다.
3. 마지막에 급하게 고친 코드가 더 나빠짐 → 남은 시간이 5분 미만이면 고치지 않습니다.
4. Python 재귀 깊이 초과 → `sys.setrecursionlimit`을 쓰거나 반복문/BFS로 바꿉니다.
